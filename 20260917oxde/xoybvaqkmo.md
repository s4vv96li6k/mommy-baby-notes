# 我院消化科已成熟开展洗涤菌群移植医疗技术

> 更新时间：2026-09-17 (UTC+8)

**1、什么是洗涤菌群移植？**

“洗涤菌群移植（WMT）”是将特定的健康人粪便中的功能肠道菌群移植到患者肠道内，重塑失衡的肠道菌群，实现肠道及肠道外疾病的治疗。
****

**2、什么疾病适合洗涤菌群移植？**

**（1）消化系统疾病：**包括营养不良、艰难梭状芽胞杆菌感染（CDI）：复发性（难治性）CDI感染；溃疡性结肠炎、克罗恩病、功能性便秘、IBS、菌群紊乱相关腹泻、肝硬化等。
**（2）肠道菌群紊乱所致的消化系统外疾病：**①神经系统疾病：癫痫、帕金森病、阿尔茨海默病（Alzheimer disease，AD）、肌萎缩侧索硬化症（amyotrophic lateral sclerosis，ALS）等。②精神系统疾病：自闭症、焦虑症或抑郁症、多动症、抽动综合征等。③代谢相关疾病：代谢综合征、糖尿病、肥胖症、脂肪肝、高脂血症等。④肿瘤相关疾病：肿瘤免疫治疗的增敏、肿瘤免疫治疗及放化疗所致肠炎等。⑤过敏性或免疫系统疾病：食物蛋白过敏性肠炎、自身免疫性肝炎、系统性红斑狼疮、强制性脊柱炎、免疫性骨关节炎、过敏性皮炎、特发性血小板减少性紫癜等。⑥成人或儿童移植物抗宿主病（graft versus host disease，GVHD）。
****

**3、怎样进行洗涤菌群移植？**

通过无痛胃镜、肠镜等方式放置给药管，将标准化制备合格的洗涤菌液，通过给药管注入消化道准确的位置，已达到治疗的控制及目的。

**4、目前常见洗涤菌群移植方式**

- 经胃镜途径：通过胃镜放入给药管，将洗涤菌液注入到上消化道，常用于上消化道疾病或更适合此部位给药的情况。

- 经结肠镜途径：利用结肠镜放入给药管，把菌液送达结肠等部位，操作相对方便，且病人舒适度最高，对于结直肠相关疾病的治疗常用此方式。

- 灌肠途径：把制备好的菌液通过灌肠的方式注入肠道。

****

**5、洗涤菌群有什么风险？**

洗涤菌群在大多数情况下是安全的，副作用有可能发生，如发热、腹痛、腹泻等，但这些症状通常在24小时内可以自行缓解。洗涤菌群是一种比较复杂的治疗方法，有着严格的供体筛选标准，包括对供体的健康状况、生活方式、传染病史等多方面进行评估。同时，在整个移植过程中，对菌液的制备、储存、移植操作和追踪都在严格的质量控制条件下进行，以确保肠菌移植的安全性和有效性。

目前我院洗涤菌群移植治疗已在多种疾病中开展实施，如难治性便秘、腹胀、慢性腹泻、艰难梭菌感染、化疗相关性肠炎、自闭症、嗜酸性粒细胞性胃肠炎等，均取得非常好的临床疗效，为许多家庭带来希望，并获得家属认可。**（供稿：儿童消化科）**
